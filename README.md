# Walking Cane

Walking Cane 是一个 Forge 1.20.1 / NeoForge 1.21.1 模组，提供不同材质的步行手杖，以及冲刺、传送和冷却存储等附魔能力。

## 手杖功能

| 手杖 | 移动/游泳速度加成 | 耐久 | 位移能力 |
| --- | ---: | ---: | --- |
| 木质手杖 | 15% | 59 | 无 |
| 铁质手杖 | 30% | 250 | 无 |
| 钻石手杖 | 50% | 1561 | 冲刺，40 tick 冷却 |
| 末影手杖 | 50% | 1561 | 冲刺、传送，传送基础冷却 200 tick |
| 下界合金手杖 | 80% | 2031 | 冲刺，30 tick 冷却 |

- 手持手杖会提供移动速度、游泳速度和跨步高度加成；生效手槽可配置为主手、副手或双手。
- 冲刺沿移动输入方向进行；没有移动输入时沿视线方向冲刺，并消耗 1 点耐久。
- 末影手杖潜行右键可传送到前方露天表面，并消耗另一只手中配置的传送消耗物。
- 末影恩赐每级可保留 1 个传送消耗物；传送距离由基础距离和消耗物数量共同决定。

## 附魔

### 冷却存储

冷却存储可以作用于普通物品和手杖。物品处于原版冷却期间时，可消耗存储次数继续使用；冷却结束后会逐次恢复存储次数。存储次数保存在物品堆自身，不同附魔等级的物品堆拥有各自的容量。

它是宝藏型附魔，不会从附魔台、村民交易或随机战利品中获得。

### 位移存储

位移存储是原冲刺存储的改名，只能对具备冲刺能力的钻石、末影和下界合金手杖生效，并可从附魔台获得。它与冷却存储冲突；如果通过特殊方式让两者同时存在于同一手杖，实际生效等级取两者中的最高等级，不会叠加容量。

位移存储也会用于末影手杖的传送冷却存储。

### 位移冷缩

位移冷缩只能作用于手杖，最高三级。它不会出现在附魔台，但可以通过村民交易和战利品表获得。每一级按配置值减少手杖冲刺和传送的冷却时长，默认每级减少 10%，三级默认最多减少 30%。

位移冷缩不属于存储附魔，可以与冷却存储、位移存储和末影恩赐共存。

## 配置

配置文件为 `config/walking_cane.toml`，首次启动时自动生成：

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `hand_mode` | `BOTH` | 手杖生效手槽：`MAIN_HAND`、`OFF_HAND` 或 `BOTH` |
| `dash_strength` | `2.5` | 冲刺速度倍率，范围 0.0～20.0 |
| `displacement_cooldown_reduction` | `0.10` | 位移冷缩每级的冷却缩短比例；`0.10` 即 10%，范围 0.0～1.0 |
| `teleport_base_distance` | `50.0` | 末影手杖无消耗物时的基础传送距离 |
| `teleport_distance_per_pearl` | `100.0` | 每个传送消耗物增加的传送距离 |
| `teleport_consumable_items` | `["minecraft:ender_pearl"]` | 末影手杖可从另一只手消耗的物品 ID 列表 |

位移冷缩的总缩短比例最多按 100% 计算，冷却至少保留 1 tick。配置修改需要重启游戏。

## 版本与构建

- `1.20.1` 分支：Minecraft Forge 1.20.1，Java 17。
- `1.21.1` 分支：Minecraft NeoForge 1.21.1，Java 21。

常用验证命令：

```powershell
.\gradlew.bat compileJava --rerun-tasks
.\gradlew.bat jar
```

`runServer` 可用于检查注册表和资源是否能在无 GUI 环境中加载。
